# NG LMS — Frontend

React (Vite) + TypeScript + Tailwind + Recharts client for NG LMS.

## Run

```bash
cp .env.example .env
npm install
npm run dev
```

Open http://localhost:5173

Set `VITE_API_URL=http://localhost:4000` (see root [README](../README.md)).
